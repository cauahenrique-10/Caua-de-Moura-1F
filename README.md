## O que tem aqui

| Pasta | Conteúdo |
| `etapa-0` | Preparando o ambiente: primeiro `console.log` |

| `etapa-2` | Variáveis e tipos (`let`, `const`, `typeof`) |
| `etapa-3` | Operadores, conversão com `Number()` e template literals |
| `etapa-4` | Condicionais (`if`, `else if`, `else`, `===`) |
| `etapa-5` | Laços `for` e listas |
| `etapa-6` | Funções (`return`, arrow function) |
| `etapa-7` | DOM e eventos: contador de cliques |
| `etapa-8` | Mini-projeto: calculadora de média, em partes (`8-1-pagina`, `8-2-esqueleto`, `8-3-media`, `8-4-validacao` e `8-5-completo`) |
| `respostas.md` | Respostas escritas dos checkpoints de todas as etapas |

## Como abrir

Cada pasta de etapa tem um `index.html` e um `script.js` (na `etapa-8`, cada parte tem a sua subpasta). Dê um duplo clique no `index.html` para abrir no navegador
Na `etapa-2`, o erro `Assignment to constant variable` na última linha é proposital: faz parte do exercício.
